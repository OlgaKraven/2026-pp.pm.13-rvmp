# Основание ПП.ПМ.13

Последний этап длится 4 недели: готовая игра → комплект для выпуска. Основной путь — Unity и текстовый редактор; сборка приложения при наличии модуля, магазин заменяется макетом.

Источники предыдущих этапов:
- https://github.com/OlgaKraven/2026-up.pm.12-rvmp — работающая механика.
- https://github.com/OlgaKraven/2026-up.pm.13-rvmp — оформление и ресурсы.
- https://github.com/OlgaKraven/2026-pp.pm.12-rvmp — три уровня, экраны, сохранения. За основу взята последняя согласованная локальная версия work/pp12, включающая правки пользователя к сдаче и началу инструкции.

Новые компоненты по сценарию: SafeAreaPanel, TutorialController, PanelTransition, AboutPanel, ScreenshotCapture. Сохраняются все 30 номеров, названий и правил; задания четвёртого этапа относятся к объяснению правил, адаптации UI и представлению результата. Учебные страницы статичные, переходы игры могут анимироваться.

Для сдачи требуется ссылка на репозиторий с Unity-проектом и хеш проверенного коммита. Сайт и два PDF создаются из content/course.json; полный runtime-код берётся из Assets/Scripts. Не создаются дублирующие разделы и копии JSON.

Обязательная учебная раскадровка заменяет видеоролик, если средств записи нет. Публичная публикация в магазине и платные сервисы не требуются. Для самостоятельной проверки вместо наблюдения за новым пользователем требуется явно указать ограничение; вымышленные результаты не допускаются.
