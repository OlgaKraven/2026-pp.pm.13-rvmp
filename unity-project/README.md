# Кристальный маршрут · ПП.ПМ.13

Unity 6.6 / 6000.6.2f1. Откройте Assets/Scenes/Main.unity и нажмите Play. При первом запуске появятся три карточки обучения; затем выберите уровень 1. Управление: WASD, стрелки или экранные кнопки. F9 сохраняет PNG в Screenshots внутри Application.persistentDataPath; путь выводится в Console.

Как играть: соберите все жёлтые ромбы и войдите в зелёный портал. Красный крест отнимает жизнь. После победы открывается следующий уровень. Кнопки «Как играть» и «Об игре» доступны в меню. Пропуск обучения сохраняется отдельно от прогресса.

SafeArea и SafeContent создаются при Play. Simulate Insets на SafeArea служит только для учебной проверки, по умолчанию выключен. Основная ориентация — альбомная. Сцены для графики создавайте в отдельном проекте, поскольку GameBootstrap создаёт игру в пустой сцене.

Версия: 1.0.0. Сохранён productName предыдущего этапа, чтобы не менять каталог сохранений. Runtime-код не включает средства редакторской проверки. Проверки перечислены в Documentation/verification.txt и документации комплекта; проверка Android не заявлена.
