# Кристальный маршрут

Контрольный пример оформления игрового продукта в Unity 6000.6.2f1. В Unity Hub выбрать Add → Add project from disk, затем папку с Assets, Packages и ProjectSettings. Открыть Assets/Scenes/Main.unity и нажать Play. При первом запуске показываются три карточки обучения. Управление — WASD, стрелки или удержание экранных кнопок; отпускание останавливает движение. Собрать все жёлтые ромбы и войти в зелёный портал. Красный крест отнимает жизнь. После победы открывается следующий уровень; прогресс локальный.

В меню доступны «Как играть», «Об игре» и настройки. F9 сохраняет PNG в Screenshots внутри Application.persistentDataPath; полный путь выводится в Console. Открытие созданного файла проверяется отдельно от сообщения.

Альбомная ориентация. Версия 1.0.0. SafeArea и SafeContent создаются при Play. Simulate Insets используется только для проверки; перед выпуском выключить. Ключи игрового прогресса и ключ обучения разные. Company/Product Name сохраняются для доступа к данным.

Practice → Export Release Artwork при выключенном Play создаёт Release/icon.png и promo.png в preview scene. Инструмент находится в Assets/Editor. Макет Release/PRODUCT-PAGE.html открыть в браузере вместе с соседними изображениями. Готовить вторую игру для графики не требуется.

Пример предназначен для необязательной сверки приёма. Индивидуальная работа выполняется в собственном проекте с правилом назначенной карточки. Исполняемая сборка и запуск на телефоне этим комплектом не подтверждаются. Происхождение ресурсов — Release/CREDITS.md.
