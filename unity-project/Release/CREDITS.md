# Источники ресурсов контрольного примера

- Игровая логика и оформление: сквозной учебный пример «Кристальный маршрут», материалы УП.ПМ.12, УП.ПМ.13 и ПП.ПМ.12 из репозиториев OlgaKraven. Изменения последнего этапа находятся в этом репозитории. Отдельная открытая лицензия предыдущих материалов не предполагается автоматически.
- Игровые фигуры: программная генерация в WorldBuilder и VisualTheme; внешние изображения не используются.
- Звуки: процедурная генерация AudioFeedback; внешние аудиозаписи не используются.
- UI и LegacyRuntime.ttf: ресурсы установленной Unity, применяются в составе Unity-проекта; не заявлены как авторские ресурсы студента.
- Иконка и рекламная композиция: созданы камерой Unity инструментом Assets/Editor/ReleaseAssets.cs.
- Игровые снимки: реальный контрольный проект, программный проверочный прогон. Это не запись наблюдения за новым пользователем.

Для своей игры замените этот перечень фактическими авторами, источниками и условиями каждого использованного ресурса.
