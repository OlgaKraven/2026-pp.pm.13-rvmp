# Источники ресурсов контрольного примера

- Логика, графическое оформление и процедурные звуки: исходный учебный пример «Кристальный маршрут» из этого репозитория. Отдельная свободная лицензия исходника автоматически не предполагается.
- Игровые фигуры создаются WorldBuilder и VisualTheme; звук — AudioFeedback.
- UI и LegacyRuntime.ttf — ресурсы установленной Unity, не авторские ресурсы студента.
- Иконка и рекламная композиция — сохранённый результат редакторского инструмента Assets/Editor/ReleaseAssets.cs.
- Снимки — сохранённые реальные кадры контрольного проекта. Они показывают состояния; не являются наблюдением за новым игроком.

В своей игре указать фактических авторов, точные источники и условия использования. Этот перечень не подменяет сведения об индивидуальном проекте.
