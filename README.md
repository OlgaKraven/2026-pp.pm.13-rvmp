# ПП.ПМ.13 «Оформление игрового продукта»

Последний этап сквозного Unity-проекта: подготовка завершённой игры к выпуску за 4 недели. Используются механика УП.ПМ.12, оформление УП.ПМ.13 и завершённая игра ПП.ПМ.12.

Новые функции примера «Кристальный маршрут»: безопасная область, три карточки обучения с пропуском и повтором, появление панелей на паузе, «Об игре» с версией, сохранение PNG по F9. Игровые правила и ключи прогресса предыдущей практики сохранены.

## Комплект

- `content/course.json`: одно задание, пошаговая инструкция, 30 отдельных вариантов.
- `unity-project`: контрольная версия Unity 6000.6.2f1, сцена `Assets/Scenes/Main.unity`.
- `unity-project/Release`: образец материалов представления игры.
- `site`: три раздела сайта, два PDF A4 landscape, полные листинги и контрольный проект; создаётся сборщиком.
- `docs/VERIFICATION.md`: фактические проверки и ограничения.

## Сборка

```sh
python -m pip install -r requirements.txt
python scripts/build.py --release
python scripts/check.py
python -m http.server 8000 --directory site
```

Студентам выдаётся задание PDF через ЛМС, подробная инструкция — по решению преподавателя. Обязательная сдача: ссылка на репозиторий с Unity-проектом, хеш коммита, PDF-отчёт и материалы Release. ZIP контрольного примера — учебная загрузка; он не заменяет студенческий репозиторий.

## Проверка в Unity

В копии проекта выполните `Practice → Verify And Capture`: проверка вызывает игровые методы и завершает редактор после сохранения результатов. Она не заменяет ручной ввод и устройство. `Practice → Export Release Artwork` создаёт иконку и рекламную композицию камерой Unity. Эти служебные инструменты находятся в Assets/Editor и не входят в исполняемый runtime.
